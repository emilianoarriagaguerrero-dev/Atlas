## Propósito

Crear una base ordenada para que el proyecto Atlas pueda crecer por etapas, con objetivos definidos, tareas claras y documentación fácil de actualizar.

## Qué incluye este repositorio

- Una visión general del proyecto.
- Objetivos principales y alcance inicial.
- Fases de trabajo para avanzar paso a paso.
- Reglas básicas de colaboración y seguimiento.
- Espacio para registrar avances, pendientes y próximas decisiones.
- Documentos separados para backlog, decisiones, contribución y recursos.

## Estado actual

Atlas queda preparado como especificación oficial inicial de documentación y planeación. Los detalles específicos del producto, público objetivo o funcionalidades futuras se agregarán conforme se definan.
