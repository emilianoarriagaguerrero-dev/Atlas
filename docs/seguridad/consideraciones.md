# Consideraciones de seguridad y privacidad

## Principios

- No publicar información sensible en el repositorio.
- No agregar secretos, llaves, tokens o credenciales.
- Separar documentación pública de información privada.
- Registrar riesgos antes de agregar integraciones externas.

## Información que no debe subirse

- Contraseñas.
- Tokens de API.
- Datos personales innecesarios.
- Información financiera privada.
- Documentos internos no autorizados.

## Antes de futuras implementaciones

Si Atlas evoluciona hacia una aplicación, se deberá documentar:

- Modelo de datos.
- Permisos y roles.
- Riesgos principales.
- Estrategia de manejo de secretos.
- Requisitos de privacidad.
