# Flujo de trabajo de Atlas

## Flujo recomendado

1. Registrar una idea, pendiente o problema.
2. Clasificarlo en el backlog.
3. Documentar decisiones importantes si el cambio afecta la dirección del proyecto.
4. Actualizar el documento correspondiente.
5. Abrir un pull request usando la plantilla del repositorio.
6. Revisar que el README siga apuntando a la documentación relevante.

## Reglas operativas

- Los cambios de documentación deben ser pequeños y claros.
- Las decisiones no deben quedar solo en conversaciones externas.
- El backlog debe reflejar el estado real del proyecto.
- Las carpetas nuevas deben tener un propósito evidente.
