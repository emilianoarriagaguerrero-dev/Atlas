# Gobernanza de Atlas

## Propósito

Definir cómo se toman, registran y revisan decisiones dentro del repositorio.

## Reglas de gobernanza

1. Las decisiones importantes se documentan antes de ejecutarse.
2. Los cambios de estructura requieren actualización del plan y recursos.
3. Los cambios de alcance deben reflejarse en producto y backlog.
4. Las decisiones técnicas se registran como ADRs.
5. La documentación debe mantenerse como fuente principal de verdad.

## Roles sugeridos

| Rol | Responsabilidad |
| --- | --- |
| Responsable del proyecto | Define prioridad y visión general |
| CTO o líder técnico | Valida arquitectura y criterios técnicos |
| Colaborador | Propone cambios documentados |
| Revisor | Verifica claridad, enlaces y consistencia |

## Criterios de aprobación

Un cambio documental queda listo cuando:

- Tiene objetivo claro.
- Está en la carpeta correcta.
- Actualiza enlaces relacionados.
- No contradice decisiones previas.
- Deja pendientes documentados si no cierra todo el tema.
