# Definition of Done documental

Un cambio en Atlas se considera terminado cuando cumple lo siguiente:

## Checklist obligatorio

- [ ] El documento tiene propósito claro.
- [ ] El contenido está en la carpeta correcta.
- [ ] Los enlaces internos fueron actualizados.
- [ ] El backlog fue actualizado si cambian pendientes.
- [ ] Las decisiones relevantes fueron registradas.
- [ ] No se agregó código accidentalmente.
- [ ] No se incluyeron secretos ni información sensible.

## Para cambios de arquitectura

- [ ] Existe contexto de la decisión.
- [ ] Se documentan consecuencias.
- [ ] Se indica estado: propuesta, aceptada o descartada.
- [ ] Se enlaza con el documento afectado.

## Para cambios de producto

- [ ] El cambio no contradice el alcance vigente.
- [ ] El impacto en usuarios está descrito.
- [ ] Los pendientes derivados están en el backlog.
