# Mapa conceptual de componentes

Este mapa describe componentes posibles de Atlas a nivel conceptual. No representa una implementación actual.

## Componentes documentales actuales

| Componente | Propósito | Estado |
| --- | --- | --- |
| README | Entrada principal del repositorio | Definido |
| Plan del proyecto | Visión, objetivos, alcance y fases | Definido |
| Backlog | Seguimiento de pendientes e ideas futuras | Definido |
| Decisiones | Registro de decisiones importantes | Definido |
| Recursos | Enlaces y materiales de apoyo | Definido |
| Resumen final | Cierre de preparación inicial | Definido |

## Componentes futuros posibles

| Componente | Propósito | Condición para crearlo |
| --- | --- | --- |
| Núcleo de aplicación | Contener lógica principal si Atlas se vuelve software | Requisitos funcionales aprobados |
| Interfaz de usuario | Permitir interacción visual | Flujos de usuario definidos |
| Persistencia | Guardar datos del proyecto | Modelo de información aprobado |
| Integraciones | Conectar Atlas con servicios externos | Caso de uso validado |
| Automatización | Reducir tareas manuales | Proceso repetible identificado |

## Regla principal

Ningún componente técnico futuro debe crearse hasta que exista una justificación documentada en el backlog o en una decisión arquitectónica.
