# Criterios para iniciar implementación

Atlas no debe pasar a código hasta cumplir estos criterios.

## Definition of Ready técnica

- [ ] Problema exacto validado.
- [ ] Público objetivo definido.
- [ ] Alcance funcional inicial aprobado.
- [ ] Flujos principales descritos.
- [ ] Modelo de información preliminar documentado.
- [ ] Riesgos de seguridad identificados.
- [ ] ADR de stack tecnológico aprobada.
- [ ] Criterios de éxito medibles definidos.

## Señales de que todavía no se debe programar

- El objetivo cambia en cada conversación.
- No existe usuario principal definido.
- No hay lista de funcionalidades iniciales.
- No se sabe qué datos manejará Atlas.
- No hay decisión de stack o arquitectura.
- No se han documentado riesgos básicos.

## Regla de aprobación

La implementación solo podrá iniciar cuando el checklist de Definition of Ready esté completo y exista una decisión arquitectónica aprobada que autorice crear código.
