# Registro de decisiones de Atlas

Este documento sirve para guardar las decisiones importantes del proyecto y explicar por qué se tomaron.

## Formato sugerido

Cada decisión puede registrarse así:

```text
Fecha: AAAA-MM-DD
Decisión:
Motivo:
Impacto:
Estado: propuesta | aceptada | descartada
```

## Decisiones registradas

### 2026-07-21 — Crear documentación base en GitHub

**Decisión:** usar este repositorio como centro principal de documentación y planeación de Atlas.

**Motivo:** mantener la información organizada, versionada y fácil de revisar.

**Impacto:** el README será la entrada principal y la carpeta `docs/` guardará documentos más detallados.

**Estado:** aceptada.

### 2026-07-21 — Separar el plan detallado del README

**Decisión:** mantener el README corto y mover la planeación completa a `docs/plan-atlas.md`.

**Motivo:** facilitar la lectura inicial del repositorio sin perder detalle en la documentación interna.

**Impacto:** nuevas secciones extensas deberán agregarse en `docs/` y enlazarse desde el README.

**Estado:** aceptada.
