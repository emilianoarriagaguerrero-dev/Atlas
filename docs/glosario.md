# Glosario de Atlas

## ADR

Registro de decisión arquitectónica. Sirve para explicar una decisión técnica, su contexto y sus consecuencias.

## Backlog

Lista priorizada de tareas, pendientes e ideas futuras.

## CTO

Rol responsable de validar dirección técnica, arquitectura y criterios de implementación.

## Documentación fundacional

Conjunto de documentos iniciales que explican propósito, estructura, reglas y próximos pasos antes de escribir código.

## PRD

Documento de requisitos de producto. Define objetivos, usuarios, necesidades, requisitos y fuera de alcance.

## Roadmap

Plan por etapas que muestra el orden recomendado para avanzar el proyecto.
