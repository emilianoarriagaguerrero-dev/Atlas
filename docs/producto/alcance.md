# Alcance de Atlas

## Incluido en esta etapa

- Documentación fundacional.
- Estructura de carpetas para crecimiento ordenado.
- Registro de decisiones.
- Backlog inicial.
- Plantillas de colaboración.
- Definición conceptual de arquitectura.

## No incluido en esta etapa

- Código de aplicación.
- Selección definitiva de framework o lenguaje.
- Diseño visual final.
- Integraciones con servicios externos.
- Automatizaciones técnicas.
- Despliegue o infraestructura.

## Criterio de cierre de etapa

Esta etapa se considera completa cuando el repositorio tiene documentación suficiente para explicar qué es Atlas, cómo se organiza y qué condiciones deben cumplirse antes de implementar código.
