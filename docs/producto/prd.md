# PRD inicial de Atlas

## Resumen

Atlas será una base documental para convertir ideas, conversaciones y decisiones en un plan accionable dentro de GitHub.

## Objetivo del producto

Permitir que el proyecto avance con claridad antes de escribir código, manteniendo visión, alcance, decisiones, backlog y reglas de colaboración en documentos versionados.

## Usuarios

- Responsable del proyecto.
- CTO o líder técnico.
- Colaboradores de producto, diseño, documentación o desarrollo.
- Personas que revisen el estado del proyecto desde GitHub.

## Necesidades principales

| Necesidad | Respuesta de Atlas |
| --- | --- |
| Entender qué es el proyecto | README y visión de producto |
| Saber qué falta | Backlog y resumen final |
| Conocer decisiones tomadas | Registro de decisiones y ADRs |
| Evitar crear código antes de tiempo | Alcance y visión técnica |
| Colaborar con orden | Guía de contribución y plantillas |

## Requisitos funcionales documentales

- El repositorio debe explicar el propósito de Atlas.
- Debe existir una estructura clara para producto, arquitectura, operación y seguridad.
- Debe haber un backlog priorizado.
- Deben registrarse decisiones relevantes.
- Deben existir plantillas para tareas, pull requests y decisiones.

## Requisitos no funcionales

- La documentación debe estar en español claro.
- Los documentos deben ser breves, mantenibles y enlazados entre sí.
- No debe incluirse información sensible.
- No debe agregarse código hasta cerrar la etapa de definición.

## Fuera de alcance

- Implementación de aplicación.
- Diseño de interfaz final.
- Infraestructura, despliegue o CI.
- Integraciones con servicios externos.
