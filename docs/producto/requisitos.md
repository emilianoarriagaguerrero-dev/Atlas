# Requisitos iniciales de Atlas

## Requisitos confirmados para esta etapa

- Atlas debe ser una base documental organizada.
- La documentación debe estar en español.
- La estructura debe estar lista para GitHub.
- Debe existir separación entre producto, arquitectura, operación y seguridad.
- No se debe generar código todavía.
- Debe existir trazabilidad mediante decisiones y backlog.

## Requisitos pendientes de definición

- Problema exacto que resolverá Atlas.
- Usuario principal.
- Funcionalidades futuras si se convierte en software.
- Datos que manejaría una futura aplicación.
- Experiencia o interfaz esperada.
- Métricas de éxito definitivas.

## Preguntas abiertas

1. ¿Atlas será una herramienta interna, pública o híbrida?
2. ¿Quién será el usuario principal?
3. ¿Qué resultado concreto debe producir Atlas?
4. ¿Qué información debe almacenar o consultar?
5. ¿Qué proceso manual reemplazaría o mejoraría?
