# Guía de contribución

Esta guía explica cómo proponer cambios en Atlas de forma ordenada.

## Antes de hacer cambios

1. Revisa el `README.md` para entender el propósito general.
2. Lee `docs/plan-atlas.md` para conocer el estado de la planeación.
3. Consulta `docs/backlog.md` para elegir una tarea pendiente.

## Flujo recomendado

1. Crea una rama con un nombre descriptivo.
2. Realiza cambios pequeños y enfocados.
3. Actualiza la documentación relacionada.
4. Revisa que los enlaces internos funcionen.
5. Abre un pull request explicando qué cambió y por qué.

## Estilo de documentación

- Escribir en español claro y directo.
- Usar títulos descriptivos.
- Preferir listas cuando ayuden a leer mejor.
- Evitar información duplicada entre documentos.
- Mantener los pendientes actualizados.

## Revisión antes de publicar

- [ ] El cambio tiene un propósito claro.
- [ ] No rompe enlaces internos.
- [ ] La información nueva está en el documento correcto.
- [ ] El README sigue siendo breve y fácil de entender.
- [ ] El backlog refleja los nuevos pendientes, si existen.
